# Competitor Deep Dive — VoIP Convergent Billing Platforms

This is the class of platform we aspire to compete with on **billing**, while differentiating with **AI/CX** and **MENA-native** capabilities.

---

## PortaBilling (PortaOne) ⭐
- **HQ:** Ukraine / global
- **Position:** carrier-grade convergent billing for VoIP and converged telecom services
- **Strengths:**
  - Real-time online charging
  - Carrier-class scale
  - Convergent billing across voice, SMS, data
  - LCR + multi-tenant + fraud controls + full API
  - Strong reseller / carrier customer base
- **Weaknesses:**
  - Carrier-focused (not friendly for SMB enterprise call accounting)
  - Complex onboarding
  - No call recording / AI / wallboards / call-center analytics
- **What to copy:** real-time rating engine, prepaid + postpaid + hybrid, LCR
- **How to beat:** SMB pricing, easier UX, AI insights bundled, MENA-native

## TimelyBill
- **Position:** UCaaS billing including 3CX
- **Strengths:**
  - Rating engine supporting 3CX integration
  - Imports unlimited usage sources
  - Consolidates invoices across voice, fax, text, video, collaboration
  - Built-in tax engine (US-focused)
- **Weaknesses:**
  - US-centric tax engine (no KSA VAT, no ZATCA)
  - No AI / no recording / no analytics layer
  - Older UI
- **What to copy:** unified invoice across multiple service types
- **How to beat:** AI insights layered on top; MENA-native tax + payment

## Telgoo5
- **Position:** wholesale voice/SMS/data + integrated billing/routing for VoIP carriers
- **Strengths:** carrier-grade routing + billing
- **Weaknesses:** wholesale focus, not enterprise call accounting
- **How to beat:** verticalize for enterprise + AI

## Splynx
- **Position:** cloud-native ISP + VoIP billing/management with full automation
- **Strengths:** ISP-friendly, modern UX
- **Weaknesses:** no AI/CX layer
- **How to beat:** AI/CX layer + MENA

## Chargesphere
- **Position:** cloud-based real-time rating, billing, policy control for telecom
- **Strengths:** policy control + rating
- **Weaknesses:** less name recognition, no CX layer

## Rev.io / LogiSense / Ubersmith / Chargebee / Cadebill / OSS360 / Cloudmore / Dynasoft TeleFactura
- Mostly enterprise telecom billing platforms
- Pricing typically high enterprise quotes

## BillMax
- Enterprise-only; ~$50k+/yr
- Quote-based; modular

## Inextrix ASTPP
- **Position:** open-source multi-tenant IP PBX with billing
- **Strengths:** open source, customizable
- **Weaknesses:** ops burden on customer; no managed SaaS option officially
- **How to beat:** managed SaaS, AI, MENA support

---

## Common feature set we must match to be "billing platform"
- **Real-time rating** (sub-second per call)
- **LCR (Least-Cost Routing)**
- **Multi-tenant** with reseller hierarchies
- **Tax engine** (configurable per region)
- **Fraud controls** (rules + alerts)
- **Full REST API**
- **Prepaid + Postpaid + Hybrid**
- **Payment gateway integration** (multiple)
- **Automated invoice generation** + dunning
- **Multi-currency**
- **Number / DID inventory** (advanced)
- **Carrier integration / SBC visibility** (advanced)
- **Whitelabel / branded portal**

## Where we differentiate vs. all of these
- **AI conversation intelligence** built into the same product
- **Wallboards / contact-center analytics** built in
- **Call recording** built in
- **Omnichannel** (they're voice-only)
- **MENA-native** (Arabic UI, Mada/HyperPay/PayTabs/Tap, ZATCA, SAMA, CITC)
