3CX Post-Call Survey — complete setup guide

Collect genuine customer satisfaction (CSAT) after agent calls using the native 3CX Call Flow Designer Survey component, then stream results into Zentryc for dashboards, per-agent scores, scheduled reports and webhook alerts.

Overview

Post-call surveys let callers rate their experience immediately after speaking with an agent. Unlike IVR-only satisfaction prompts, this pattern uses 3CX's dedicated CFD Survey component so you capture structured answers (yes/no, 1–5 scale, voice comment) and POST them to Zentryc in real time.

Once ingested, responses appear on the Survey Dashboard, link automatically to the originating call when possible, roll up into agent and queue CSAT tiles, and can trigger survey.completed webhooks or scheduled survey_summary reports.

Where to find Survey Settings: In the Zentryc portal, open the sidebar Settings section (not Contact Center) → Survey Settings. Company admins and superadmins only.

Prerequisites

  • 3CX Enterprise with Call Flow Apps / Call Flow Designer license
  • Zentryc tenant with surveys provisioned (survey_enabled and survey_cfd_verified — your account manager enables these)
  • HTTPS connectivity from the 3CX PBX host to https://connect.zentryc.com
  • Windows PC with 3CX Call Flow Designer installed to build and export the survey app
  • Company admin login on Zentryc to configure campaigns and copy the ingest token

Step 1 — Zentryc portal setup

  1. Sign in to connect.zentryc.com as a company admin.
  2. Open Settings → Survey Settings in the left sidebar.
  3. Under Tenant Feature Flags, enable both:
    • Survey enabled — turns on survey menus and ingest for your tenant
    • CFD verified — confirms your 3CX estate has Call Flow Designer; required for the sidebar to show survey pages
  4. Click Save Flags.
  5. In Campaign & Questions, configure the default Post-Call CSAT campaign. Question tags must match your CFD Survey component (see table below).
  6. Click Save Campaign.
  7. From the CFD Integration card, copy:
    • Ingest URL — https://connect.zentryc.com/api/v1/survey-responses/ingest/
    • X-Survey-Token — unique per campaign; treat as a secret
    • Campaign slug — typically post-call-csat

Recommended question mapping

OrderTypeTagPrompt (example)
1Yes/NosolvedHave we resolved the issue? Press 1 for yes, 2 for no.
2Range 1–5ratingRate the attention received, 1 to 5.
3RecordingcommentsLeave a comment; press # when finished.

Step 2 — Build the CFD project

Reference: 3CX CFD Survey component documentation.

A. Create the survey flow

  1. On Windows, open 3CX Call Flow Designer.
  2. File → New → Callflow Project — name it ZentrycPostCallSurvey.
  3. Drag a Survey component onto the canvas; rename it CustomerFeedback.
  4. Configure the three questions with tags solved, rating and comments exactly as in the portal.
  5. Add an output field: name caller, value session.ani.

B. Parse survey results (if needed)

The Survey component outputs a CSV Result string. If your HTTP body needs individual variables, add Execute C# Code blocks per the 3CX docs to split values into GetSolvedResponse, GetRatingResponse and GetRecordingResponse return values.

Step 3 — HTTP POST to Zentryc

After the survey completes, add a Web Service REST or HTTP Request component:

SettingValue
MethodPOST
URLhttps://connect.zentryc.com/api/v1/survey-responses/ingest/
HeaderContent-Type: application/json
HeaderX-Survey-Token: <token from Survey Settings>

Body (Expression Editor):

{
  "campaign_slug": "post-call-csat",
  "caller": "{{session.ani}}",
  "agent_dn": "{{session.variable.agent_dn}}",
  "queue_dn": "{{session.variable.queue_dn}}",
  "answers": [
    {"tag": "solved", "value": "{{GetSolvedResponse.ReturnValue}}"},
    {"tag": "rating", "value": "{{GetRatingResponse.ReturnValue}}"},
    {"tag": "comments", "value": "{{GetRecordingResponse.ReturnValue}}"}
  ]
}
Tip — better call linking: Pass agent_dn and queue_dn from your queue disconnect script when the call ends. Zentryc matches responses to CDR records within a configurable time window; agent/queue context dramatically improves match confidence.

Deploy the CFD app

  1. Build → Build All — produces ZentrycPostCallSurvey.zip.
  2. 3CX Management Console → Advanced → Call Flow Apps → Add or Update.
  3. Assign a DID or extension to the app — this is the number queues will transfer to after calls.

Step 4 — Trigger survey after agent calls

PatternConfiguration
Queue disconnect (recommended)Queue → After call → Transfer to survey CFD DID/extension
IVR opt-inIVR menu option routes caller to the survey DID
Outbound callbackCustom CFD entry with same ingest POST block

Ensure the queue script sets session.variable.agent_dn and session.variable.queue_dn before transfer when your 3CX version supports session variables on disconnect.

Step 5 — Verify end-to-end

  1. Place a test call through the queue; when the agent hangs up, complete all survey prompts.
  2. Open Contact Center → Survey Dashboard — the response should appear within ~2 seconds.
  3. Open Survey Responses → click the row → check match confidence (exact, heuristic or unmatched).
  4. Optional API test with curl:
curl -X POST 'https://connect.zentryc.com/api/v1/survey-responses/ingest/' \
  -H 'Content-Type: application/json' \
  -H 'X-Survey-Token: YOUR_TOKEN' \
  -d '{"campaign_slug":"post-call-csat","caller":"966501234567","answers":[{"tag":"rating","value":"5"}]}'

A successful ingest returns HTTP 201 Created. Duplicate submissions for the same caller and timestamp are idempotent (HTTP 200).

Dashboard, reports & alerts

  • Survey Dashboard — CSAT score, response volume, solved rate and trends (Contact Center menu).
  • Agent & queue detail pages — CSAT tiles when surveys are linked to calls.
  • Scheduled reports — report type survey_summary in Call Center → Reports.
  • Webhooks — subscribe to survey.completed for CRM or ticketing integrations.
  • Alerts — optional CSAT threshold rules via the notification engine (survey_csat source).

Troubleshooting

SymptomLikely cause & fix
HTTP 401 on ingestWrong or missing X-Survey-Token. Copy fresh token from Survey Settings; update CFD app.
HTTP 403 on ingestSurvey flags disabled or campaign not license_verified. Enable both flags and save campaign.
No Survey menu in portalBoth survey_enabled and survey_cfd_verified must be true for the tenant.
Responses show "unmatched"Pass agent_dn/queue_dn; widen match_window_minutes on the campaign.
Duplicate responses in CFD logsIngest is idempotent — safe to retry; same caller+time returns 200 without duplicate rows.
CFD POST fails SSLEnsure PBX can reach connect.zentryc.com on 443; check firewall allow-list.
Tags mismatchPortal question tags must exactly equal CFD Survey tags (solved, rating, comments).

API reference (read access)

Authenticated API clients with read:surveys scope can query:

  • GET /api/v1/survey-campaigns/ — list campaigns
  • GET /api/v1/survey-responses/ — paginated responses
  • GET /api/v1/survey-metrics/ — aggregated CSAT metrics

See API Docs in the portal for OpenAPI details and token scopes.
